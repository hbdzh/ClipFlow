# ADR-0012：macOS转码与批处理使用同一Core队列

- 日期：2026-11-10；状态：Accepted（Integration审定接入边界，实测结果另记）。
- 基线：main `840a5edc80af01ebb13cd3f9806ec3c019a5c85f`，已含CORE-004。

## 决定

MAC-003只接入既有CORE-004消息，不修改公共契约、八函数ABI、Rust实现、依赖或平台最低版本。Swift表达用户选择，Rust继续决定媒体支持、预设编码参数、音轨映射、输出保护、顺序、容量与执行。转码明确为有损重编码，快速流复制与精确裁剪继续单独呈现；不支持组合展示实际原因，不静默降级。

工作区所有真实导出共用一个CORE-004 export engine，使每engine的32项活动容量也是此原生宿主的总活动容量。轻量探测与预览独立，但不得通过新增export engine绕过容量或调度约束。旧mock/旧媒体自测显式使用兼容配置，不改变既有黄金预期。

批量提交在FFI调用前冻结本机素材UUID、来源、请求范围、预设、音轨、目标及配置，并持有来源/输出目录访问。本机UUID与本次engine中的job_id建立映射，不能把不同engine可重用的job_id当全局身份。提交回执中的job_ids按索引关联冻结条目；Core原子拒绝不产生假排队项。批量预检同步且可能耗时，所有FFI在actor串行后台执行。提交中取消先记录意图，收到真实IDs后逐项取消，不放弃仍在运行的调用或访问。

Core队列快照是运行项、排队项及顺序的唯一来源。排序发送全部当前queued IDs的精确排列，快照竞态导致拒绝时重新读取实际状态，不保留假顺序。取消成功调用不等于已取消，直到Core终态才能显示完成并释放借用。失败/取消后的重试使用新目标及新submission_id，保留原任务记录；由Core重新验证原冻结请求，不覆盖来源或已有结果。

提交幂等身份在不确定回执期间保持稳定，不能通过新token制造重复作业。成功结果按策略解析验证证据：转码允许只保留被选择音轨，必须有Core的所选音轨验证与实际plan；不得把旧的“全部源流保留”硬套在静音或单轨输出，也不能放宽旧流复制/精确裁剪证据。

最近任务仅保存本机有界摘要/授权书签，不持久化原生句柄，不自动续跑。重启的未完成项标中断；缺少来源或授权时提示重新授权，不能推断后台恢复成功。Core历史过期/清除需处理NOT_FOUND，不能凭旧ID重建任务。退出、CLEANUP_FAILED与未确认清理继续保留owner和访问，整体关闭的15秒看门狗不伪造释放。

## 分工与验收

| 责任 | 独占范围 |
|---|---|
| Integration | ADR、任务卡、交付/风险与实际窗口走查 |
| Swift桥接 | CoreBridge及专属队列DTO，指针/缓冲/同engine串行与策略结果解析 |
| macOS平台 | 其余apps/macos界面、生产状态模型、授权/摘要和同模型场景入口 |
| 独立QA | 新tests/mac_003、独立媒体和原生模型证据，不改既有黄金预期 |

需执行原生编译、旧桥接/剪辑回归、真实多素材预设/选轨/批量、混合结果、排序/取消/重试/关闭与独立ffprobe/全解码/源哈希检查。实际GUI走查与原生CLI分开记录。没有实测的VoiceOver、窗口尺寸、深色、沙盒、Intel和其他系统不能继承PASS；GUI试用使用隔离构建/摘要，保留用户当前main应用现场。正常构建继续使用原开发bundle身份`local.mediastudio.ui001`，保留既有本机摘要；仅验收产物用显式构建环境选择`local.mediastudio.mac003`/独立名称，不能以切换默认身份造成历史无声消失。当前验收包的身份及复现环境记录在build证据，产物不入库。

## 风险与后续

本轮仍为本机arm64非沙盒开发构建。最近摘要不等于跨重启作业恢复，授权计数配对不等于沙盒分发验证；完整主观音画/色彩、最大32×10分钟压力、硬件/Intel/其他系统及正式签名发行均需后续证据。清理隔离状态需保留现场并重新启动进程恢复，不提供伪修复。MAC-003不代表macOS首版完成，下一张AI-001仍需模型和运行时许可与真实推理验证。
