# ADR-0010：macOS多素材工作区与显式剪辑语义

- 日期：2026-11-10；状态：Accepted（Integration审定平台/桥接分工，实现及验收另记）。
- 基线：CORE-003提交aabcb8f，经e377800b85b43fce9a8b2379f804f68478aef239合入main并推送；远端实际核对一致。

## 决定

MAC-002在既有UI-001原生工作区接入已审定CORE-003，不改变Rust/Core公共契约/八函数ABI/依赖/平台最低版本。普通界面明确core003_enabled，快速选择mp4_h264_copy_v1，精确选择mp4_h264_standard_v1且说明有损重编码；默认mock/旧桥接自测和旧media-self-test显式legacy兼容，不改历史黄金预期。用户无需理解profile/FFmpeg参数，这些只在薄桥接和诊断详情。

已有单素材全局phase不能安全代表导出A同时选中B，因此将素材状态与真实导出状态分离。Asset有本机UUID、规范文件身份、授权URL、独立选区/模式/探测状态；一个全局原生预览带generation防旧回调，选中对象变化不能改已提交任务。导出记录捕获asset UUID/来源/范围/模式/组件配置/目标和本次CoreBridge返回的job_id，任务用本机UUID标识，不把可跨engine重复的job_id当全局身份。

最多100素材，批内和已有素材按文件身份去重后整体检查容量；超限不半导入。单活动导出是当前Core已接纳能力，不在UI造排队/批量/排序/自动重试；该能力仍属CORE-004。任务/结果列表显示真实Core状态及有界摘要，不能把未提交事项写成queued。允许选择其他素材和查看结果而不改变活动快照。

probe bridge与export bridge隔离，避免切换/探测阻塞或关闭活动导出；probe批结束/空闲回收Core retained jobs，不让重复导入耗尽256历史容量。Core调用/销毁在actor后台，主线程只更新类型化值；准确结果使用其真实验证字段，不套旧stream-copy字段或因optional缺失误报已验证。

## 所有权与边界

| 行为 | 唯一责任 |
|---|---|
| 媒体模式/范围/编码/任务/取消/验证/输出保护 | 已有Rust Core；本轮不改 |
| UTF8消息/DTO、指针/缓冲、engine关闭 | CoreBridge actor；Rust原ptr/len单次free，异常/解码失败亦释放 |
| 素材身份、选中状态/键鼠/系统面板/拖放/任务摘要 | WorkspaceModel与原生view，不计算FFmpeg业务 |
| 原生播放/规范时间与旧异步回调防护 | PreviewController；不把预览位置当精确无损落点 |
| URL授权 | 平台按借用期持有；probe/预览/导出/验证/清理均结束后才释放 |
| 独立真实媒体/错误/资源验收 | QA新增tests/mac_002；Integration实际窗口走查 |

切换素材不会释放活动导出/预览仍借的来源；移除应拒绝或先确认相应借用已结束。单独输出父目录授权覆盖导出及失败清理；start返回true必须对应一次stop，false不直接推断权限被拒。关闭等待所有probe/preview加载与Core任务停止，BUSY不消费owner；清理不能确认时保留owner/访问、显示错误并拒绝假关闭成功。

应用整体关闭由model持有唯一cleanup task；15秒仍未确认时主线程报错并保留stopping/owner/授权，继续等待真实清理，不能通过取消调用者、丢弃task或提前释放来伪造关闭完成。重试复用尚在运行的cleanup，完成后才释放访问；CoreBridge既有CLEANUP_FAILED仍fail-closed。此增量针对AC16，独立注入延迟真实cancel验证，不改变媒体请求与ABI。

最近最多100条摘要仅保用户本机元数据/授权bookmark，可清除。重启不保存/复用engine/job handle、不自动续跑；未完成项标已中断待人工重试，不假称清理已完成。失效授权/结果移动要重授权或说明失效，不私自扩大访问。普通日志不写完整用户路径/内容，不上传历史/素材。

## 交互与验收

保持系统Open/Save、菜单、拖放、Tab/键盘、Space不抢文本编辑、浅深色和两种窗口尺寸；关键控件AX标签/焦点可检查，完整VoiceOver朗读若未实测须另记。未知进度用不定指示，失败/取消以Core终态为准，结果绑定原任务来源/模式/请求与实际范围。转码/AI入口若保留必须清楚说明未实现，不提供伪成功。

成功：多选A/B→各自probe/选区→A明确精确导出时切B调整其范围→A结果仍对应A/原区间/P01且独立检查通过。失败1：超过100唯一素材全批拒绝、不丢原工作区；坏输入可修复后导入有效素材。失败2：缺编码器/已有目标/取消或关闭→明确原因和可确认清理，无假结果、不丢访问所有权。

平台提供同生产model/bridge的workspace-self-test驱动供QA独立执行；它不是替代生产实现的测试模型。旧UI-001自测保留回归，新的快速/准确输出独立probe/全解码/帧/轨/时轴/质量验证。原生窗口操作/截图另行记录，不能用CLI通过代替键鼠/布局/辅助功能实测。

## 风险与回滚

本机macOS27.0.1 arm64 / Swift6严格并发基线，不证明Intel/旧OS/沙盒/正式发行。书签和权限配对不等于沙盒分发验收；最近摘要不等于跨重启作业恢复。单活动作业也不等于未来32项队列已实现。若新UI/生命周期不安全，保留Core与旧legacy自测，拒绝新任务并报告现场，不静默回退导出策略。新契约/依赖/最低版本变化需另审，不能由UI自行决定。

本轮完成后下一张CORE-004；MAC-002不等于完整macOS首版，转码/AI/开发包和最终QA尚待后续卡。
