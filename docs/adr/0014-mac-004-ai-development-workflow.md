# ADR-0014：MAC-004 受控本机音源分离工作流

日期：2026-11-13。状态：**Integration/Core 开发决策；实现与验收以实际测试为准**。本决定在 [AI-001](../../contracts/AI-001.md) 已接收的 macOS arm64 受控开发路径上构建原生工作流；不改变八函数 ABI、公开 capability、模型权利或发行结论，不将其标为普通用户生产能力。

## 职责和授权

| 层 | 职责 |
|---|---|
| SwiftUI/AppKit | 选择本地音频、显示模型和任务状态、播放 Core 生成的两条音轨、选择导出位置与显示结果。 |
| macOS 文件适配 | 在后台将授权源复制入应用自持的受控工作区，并在用户选择的位置将两条已验证音轨作为一组导出；持有必要文件访问授权。这是文件传输，不做 FFmpeg 业务决策。 |
| Rust Core | 模型和输入校验、唯一队列与重任务调度、音频规范化、worker 启停、取消、输出验证和工作区内两音轨的事务发布。 |

AI-001 当前要求配置显式 `development_root`、根目录为当前 UID 拥有的 0700 目录，源与结果是其中单层叶，`ai_separation.available=false`。MAC-004 的受控开发路径通过应用新建的私有工作区满足此条件，不改变 Core 的输入/输出或能力定义；不要将此开发路径显示为已接收的普通产品功能。运行时、worker 和固定模型通过已配置的本机路径提供，缺失或不匹配时清楚反馈；不自动下载或将个人环境路径硬编码到发行物。

## 生命周期

1. 用户选择本地音频，应用在后台复制到私有工作区独占的新文件；源文件只读且不作临时文件。工作区路径解析为无符号链接的实际绝对路径，以满足 Core 现有限制。源访问授权持续到复制完成。
2. 提交既有 `ai_separate` 请求，固定模型 ID 为 `umx_hq_vocals_onnx_v1`；源与新结果目录均位于相同工作区，作业排队、状态、失败和取消来自 Core。界面未知进度显示不定进度；未实际收到 job ID 不声称成功入队。不得把 capability=false 改写成公开能力可用。
3. 作业成功后，仅将 Core 返回的结果目录及固定的 `vocals.wav`、`accompaniment.wav` 供原生播放。两条独立试听；不自动调整内容、截幅或改变采样率。取消和失败不得提供成功输出；退出或切换时先依 Core 状态确认回收再清理应用拥有的工作区，清理无法确认则保留相关工作区。
4. 用户选择导出父目录后，后台在该目录创建本次独占临时目录，复制两条成功音轨，再使用同卷 `renamex_np(RENAME_EXCL)` 或等价无覆盖目录操作将它们一次发布到新目录。不得覆盖已有对象或逐条把半组发布到最终目录；失败清理本次临时目录，不触碰源和已有目标。只在成功发布后报告可打开的导出结果。所选文件夹授权持续到操作完成。输出和工作区可以位于不同卷，因为复制在目标卷完成，最终发布发生在目标卷内；缺少所需排他原语时明确失败。

## 验收范围

仅针对改动执行必要的 macOS 原生构建与真实授权音频闭环：导入、真实 Core 两输出、取消及清理、两轨实际播放、导出后独立解码和帧数/时长核验；模型缺失/错误及目标已存在应有清楚错误。记录构建、输入来源和未验证项。真实播放/听感、不同用户授权、App Sandbox、其他平台、安装包和发行条件各自记录；不得将 Core 本机测试直接宣称为 UI 实测。用户要求不运行全量或过度测试。

**边界：**受控开发工作区不防御恶意同 UID 修改；辅助程序隔离、普通用户文件权限、模型安装/分发、正式签名以及源/目标异常和崩溃恢复未因本文自动通过。不同线程须通过现有 bridge 串行持有 Core engine；不能让 FFI 指针穿越 actor 安全边界。任何 IPC 或接口变动另审。

## 沙盒文件授权复核（待实测）

跨应用退出保存文件访问应使用系统安全范围书签并在实际读取期间开启、结束后释放访问；书签过期、无法解析或实际读取失败时提示重新选择。普通或 minimal bookmark 不等同持久沙盒授权。源只需要读取，导出应通过系统面板明确授权目标父目录，随后在该授权目录内创建独占暂存并发布；只选择一个新目标 URL 不自动证明同级暂存目录可写。是否保存所选路径及其有效期应与实际用户流程一致，不保存密钥和音频内容。

测试包如启用 App Sandbox，需审定 user-selected 文件访问、app-scoped bookmark entitlement 和签名身份。ad-hoc 签名的验收仅覆盖当次测试构建及实际权限，重启同一二进制不等于重建后身份或正式证书；沙盒内真实执行 Python、其依赖和 FFmpeg 时需分别实测。这里是实现与测试约束，不代表沙盒、安装包或分发已接收。[Apple 文件授权说明](https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox)及[书签 entitlement 说明](https://developer.apple.com/documentation/professional-video-applications/enabling-security-scoped-bookmark-and-url-access)为相关来源。
