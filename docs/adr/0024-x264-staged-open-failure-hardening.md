# ADR-0024：x264 初始化失败的分阶段防御修补

日期：2026-11-16（工作从11月15日开始，证据目录沿用开始日期）。状态：Proposed，待独立 Integration 审查具体补丁/配方。范围为本机 macOS arm64 开发候选，不批准公开发行。

## 问题与决定

Release-v2 已修 x264 `31e19f92f00c7003fa115047ce50978bc98c3a0d` 的参数副本泄漏。后续静态审查确认，encoder-open 在更晚阶段失败仍可能遗失其他资源；当前官方 master 固定提交 `0480cb05fa188d37ae87e8f4fd8f1aea3711f7ee` 的失败尾部仍只有顶层释放。CVE-2025-25467 的 CNA/CVEProject 当前记录未给出精确受影响范围或修复提交，其 AAC/RCE 描述不能由已知泄漏直接证明。

在原参数补丁之后应用一个局部防御补丁（SHA256 `7afd0b624a5b1ccec94372eceef282767e0a278e0b01e9085ed58e2ac59b2016`），包含：

- 同步列表按成功初始化的 mutex/condition 逐步回滚。
- 线程池仅在全部成功后发布；失败时只 join 实际创建的线程，只销毁已成功构造的列表。
- lookahead 延迟发布，失败时清理新建的私有列表、cache 和 lookahead scratch，保留调用方分配的额外 context，移除借用别名。工作线程创建是最后一个可能失败的操作。
- encoder-open 记录独占前缀与两个成功但仍空闲的 pool；在共享 context/OpenCL 建立前失败时清理 pool、CQM、costs、数组、NAL 缓冲及 reconfig 容器。之后停止该局部回滚。
- CQM 自身末尾校验失败改走既有 fail，避免 helper 回滚后再次外层 delete。

不改编码公式、公共 ABI 或结构体布局。原归档、参数补丁及组合补丁按顺序使用，不能再叠加已被组合补丁包含的前缀草案。五份源文件的应用前后摘要必须与独立复审一致。成功路径参数和输出通过正常有效媒体回归核对；未审查前不构建候选。

## 剩余边界

共享 encoder frame/context、非 lookahead scratch/border/deblock、ratecontrol/平台资源，以及 lookahead 已成功创建后更晚失败的父级状态，仍没有统一安全析构契约。通用 delete 或完整 encoder-close 依赖已建立的锁、线程与共享关系，不可直接接到所有失败出口。构造函数自身失败回滚不等于父级晚期失败时已清理其成功创建的子对象。局部补丁不声称覆盖这些状态，更不声称完整 CVE 已修。

Core 的 `-threads 1` 位于输入 `-i` 之前，不能当作输出 libx264 单线程的证据。当前产品仍可能使用编码线程；以单任务 helper 进程退出回收资源是额外缓解，不是组件无缺陷或代码执行不可能的证明。

## 责任与兼容性

| 层 | 责任与变化 |
| --- | --- |
| 原生 UI / Rust Core | 保留请求、预设、路径安全、队列与取消语义；无公共类型/八函数 ABI 改动 |
| FFmpeg wrapper | 保留7.1.5及固定参数；调用者与编码器内部资源所有权分别审查 |
| x264 / 构建 | 固定原提交与补丁组合，仅局部资源回滚；不重写编解码算法 |
| QA / Integration | 独立状态/别名/线程审查，再核对构建与正常有效媒体回归，限定结论范围 |

ORT、worker、模型/图、SDK最低版本、签名权限不变。其他平台/Intel不继承本机结果。

## 验证与工件

Release-v2 154文件与原171份证据保持不变。若补丁准入，使用全新构建目录、新候选 Release-v3，并保留源码/补丁/库/签名前后摘要、GPL材料和源代码披露。执行普通有效媒体的精确/P01/P02/快速回归、队列/文件边界及静音原生导出；增加线程池正常生命周期与正常导出/取消资源验证，不扩大为重复整张QA。

失败分支的所有权结论按 STATIC_ONLY 标记，不能把正常成功编码伪称为逐个初始化失败已动态验证。禁止获取漏洞样本、构造恶意媒体或运行漏洞复现/故障注入；全程不打开 VoiceOver、不播放或试听。局部补丁的运行回归与完整CVE裁定分开。

## 阻塞与后续

完整CVE需要CNA/上游明确受影响/修复提交、具体弱点及AAC/RCE依据。后期资源清理需要可复审的分阶段所有权与构造安全析构方案，不能以泛化close替代；是否另做该范围的设计与验证应独立记录。公开分发/GPL履约、专利/渠道、真实签名公证与其余QA MUST继续单列。
