# ADR-0011：CORE-004显式转码、原子批队列与资源所有权


## 决定与责任

采用[CORE-004契约](../../contracts/CORE-004.md)显式opt-in，在现有八函数ABI上使用版本化JSON控制消息，不改变旧mock/trim配置与输出。没有新增registry依赖、编解码器或SDK最低版本；继续使用已审定外部FFmpeg7/libx264/AAC开发路径，不打包GPL构建，不声称分发已合规。

| 行为 | 唯一所有者 |
|---|---|
| 纯请求类型、profile/音轨枚举、严格语法与几何纯规则 | media-domain，Core engine负责人 |
| 原子接收、ID去重、32/100上限、FIFO/重排/重试、全局重permit、取消状态 | media-orchestrator，Core engine负责人 |
| 已准备源/目标、全源支持验证、固定argv、P01/P02转换与真实内容校验、空间预算RAII | media-ffmpeg，backend负责人 |
| UTF8/缓冲/错误隔离、控制消息和CLI薄入口 | media-ffi/media-cli，Core engine负责人；Integration强制复审 |
| 公共契约/ADR/状态与合并 | Integration root；平台不单独扩协议 |
| 新独立fixtures/物理输出/失败注入/兼容验收 | QA；不改旧黄金预期 |
| 转码/批量原生界面及本机历史授权 | 后续MAC-003；本卡不改apps |

## 为什么需要新模式

旧mpsc单engine FIFO和终态max_jobs不能满足待执行重排、整批原子接收、100近期与跨engine一个重任务。UI循环单提交会产生部分接收/重复作业，也无法保护已提交快照，因此不在平台层拼队列。采用Core持有统一队列/不可变准备计划、进程重permit与同卷预留，不另造状态机或客户端FFmpeg参数。

P01复用准确编码；P02仅增加固定尺寸/质量/码率与明确源音轨选择，先验证完整源布局再选择。无音轨不造静音，选none不掩盖不支持布局。缩放参考与源帧身份分开检查，避免拿不同尺寸PSNR或只看标签判成功。需要新能力的客户端显式打开core004，旧客户端仅用已兼容请求。

## 资源、安全与兼容

每队列engine32非终态、100终态/近期和100 accepted去重记录均有回收定义；产品宿主总量32由后续MAC-003共享单一queue engine或明确协调，不把跨engine总量当已验证。进程全局只承诺1重permit。不能依赖无限保留job_id；重试必须新ID/新目标。准备批在接收前完成已知项预检，失败RAII全部释放；允许受控临时权限探针，但无ghost作业/最终目标。源变化/目标竞争仍会在接收后发生，执行时重检并逐项失败后继续。

同卷budget/空间floor由backend全局持有，非终态保留，真实清理终态才释放；捕获stdout预算不等于输出文件预算。使用宿主/bin/df而不新增unsafe/libc依赖，解析和失败显式处理，仅macOS已接纳后端，不把系统工具存在推断其他平台可用。所有实重任务含旧engine共享permit，避免新旧混用绕过限制；等待permit仍queued可取消重排。

每项Prepared记录预检已耗Duration，执行扣除并共享对应操作总预算；排队/其它项预检的闲等不计。Probe/copy、准确Trim、转码分别用自身期限，准确Trim预检不能套copy关键帧planner。同步预检受操作期限且后台串行调用，不承诺同handle并发取消；运行cancel/destroy既有所有权与清理保证不变。目标预留及重试按父目录dev/ino与OS create_new探针判别名字等价，修复已实测的大小写/NFC别名漏检；仅删除自己创建的marker。queue快照另提供global scalar以区分active计量与清理失败后仍保留的进程预留。无法确认时保留owner/授权，不把有限测试称作无泄漏。实际空间竞争、进程失败、源变化仍可能发生，返回结构化错误并保护源/目标。

## 首个可验证路径与回滚

成功：原子接收A/P01全部音轨与B/P02指定第二源音轨，重排待执行，再逐项核对帧/尺寸/音轨/时轴与无覆盖提交。失败1：批中一个已有目标/坏范围/资源不足，整批无ID/最终输出。失败2：接收后改源或抢占目标，该项失败而其余继续；活动取消先观察非空staging/PID再确认回收。

先冻结失败契约与独立阈值后实现；旧测试不修改，默认flag关闭可回到已验证旧子集，不能静默用旧操作替代新请求。原生UI、其他平台、硬件、分发与最大负载留待后续实测；MAC-002的Q10 PARTIAL继续保留。下一张MAC-003，不自动启动。
