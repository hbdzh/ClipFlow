# ADR-0029：受控画面变换开发扩展

状态：草案，待 Integration 复审；不代表平台或发行验收。

背景：截图要求旋转、缩放和位置调整。既有 CORE-004 将滤镜及几何固定在核心，不能由 SwiftUI 构造命令，流复制也不能实现这些像素变换。

决定：以默认关闭的 `video_transform_enabled` 控制严格整数对象，只在显式有损标准转码中应用。几何、交互、校验及拒绝边界见 `contracts/CORE-VIDEO-TRANSFORM.md`；保留旧 ABI 和无变换请求行为。重试继承原请求，同一批提交 ID 对不同变换发生冲突。

| 层 | 责任 |
| --- | --- |
| 原生 UI | 收集并冻结四个值，区分预览与输出，清楚提示有损与不支持情形 |
| Rust domain | 验证输入、单位及版本兼容，拒绝未知字段 |
| Rust orchestrator | 队列、去重、重试、取消以及摘要 |
| FFmpeg 适配器 | 根据有界参数构造滤镜和输出检查，不执行客户端脚本 |

首次验证：非对称色块、90°顺时针、位置偏移和黑边、比例 150%，独立抽样输出帧，记录探测与完整解码；超界参数、目标存在、未开启配置拒绝。其余输入、P02、内存峰值、重任务取消、沙盒、跨平台和主观体验必须分别验证。回滚为关闭 opt-in；不得静默移除参数并按旧请求执行。依赖未新增。
