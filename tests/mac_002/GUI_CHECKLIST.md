# MAC-002 Integration 实际GUI走查清单

本表是待执行动作，不是GUI已通过。由root独占CUA执行；QA CLI不争用桌面。

1. 首次打开：素材/预览/快速与精确模式/提交/任务结果在1分钟内可找到；1200×800和1600×1000点无关键信息遮挡，检查浅色/深色。
2. ⌘O多选A、B和重复A：两个唯一素材；拖放同样来源不重复。取消Open不清空原工作区。
3. A选1.1–2.6快速、B选0.4–1.7精确，来回切换检查各自范围/模式/元信息/画面不串；Space只在非文本编辑时控制当前预览，Tab/方向键可达主操作。
4. A提交新目标并在活动中切B，检查任务仍显示A/快速和原范围，B不自动提交；A完成后请求/实际范围和Finder结果绑定A。
5. B精确提交，显示“重编码/有损”及Core实际范围，不出现“精确无损”；打开结果/Finder与选中任务关联，不能默认打开当前素材的旧结果。
6. 错误恢复：无效范围阻止提交，修复后可导出；已存在目标不覆盖；坏媒体和不支持输入有解释，选有效素材可继续；不要为GUI演示误删用户文件。
7. 正常取消/活动关闭：等待“正在停止/清理”再终态，不即时假取消；重开工作区无旧活动handle续跑。
8. 最近任务：关闭重启显示本机摘要，清除可用；结果已移动/删除时不能假装可打开；历史不变成活动任务。
9. VoiceOver实际尝试读素材、模式、时间码、导出、取消、任务/结果，记录能读/焦点顺序与未覆盖项；AX树文本可读不自动等于完整VoiceOver通过。
10. 所有真实输出另交独立probe/全解码/内容/时轴检查；截图不是媒体保真证据。记录App/库SHA及未测项，完成CUA后必须按工具要求发送completion_summary。
